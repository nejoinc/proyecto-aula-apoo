# StudyBox

Aplicacion para estudiar mejor con tus archivos.

## Que hace

- Lee archivos de texto
- Genera flashcards
- Hace quizzes
- Convierte texto a audio
- Chatbot para preguntas

## Como usar

1. Instala Python
2. Clona este repositorio
3. Instala dependencias:

```bash
pip install -r requirements.txt
```

4. Crea archivo `.env` con tu API key:

```
GEMINI_API_KEY=tu_api_key
```

5. Ejecuta:

**Con interfaz grafica (GUI):**
```bash
python main_gui.py
```

**En consola:**
```bash
python main.py
```

## Archivos soportados

- TXT
- MD
- PY
- JSON
- CSV

## Interfaz Grafica

La GUI tiene botones para:
- Subir archivos
- Procesar archivos
- Listar archivos
- Chatbot
- Generar flashcards
- Generar quiz
- Generar audio
- Ver conceptos clave
